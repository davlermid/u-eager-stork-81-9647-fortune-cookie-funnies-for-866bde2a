Entry for the make.fun bounty **Fortune Cookie Funnies for Engineers**
($2, winner takes all). `main.ts` writes one fortune-cookie line for a
software engineer to `/output/entry.txt`:

> Your standup update will be 'same as yesterday' until retirement.

65 characters, no trailing newline. Ten candidates were scored 1–5 against
each of the five judge criteria; this line scored highest (23/25) — a
classic second-person fortune shape, a standup twist only an engineer
lives, and the funniest word, "retirement", sitting at the end.

Run it with Node 22:

```sh
node main.ts
```
